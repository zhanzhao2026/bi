## 2. 各阶段详述

### P0 调研与定稿(W1~W3)——本项目成败的关键期

- **范围**:数据摸底(现有 ADS/DWS 盘点、可查询表/口径现状)、指标字典工作坊(30~50 个 P0 指标逐条签收)、架构评审定稿、语义 YAML v0、LLM 双轨 PoC(2~3 候选 × 同一评测集)、Golden Set 首批 50 题。
- **交付物**:口径字典 v1(业务签收)、架构定稿、PoC 报告(模型选型+成本)、评测基线报告。
- **准出**:M0 评审通过 = 口径有签收、PoC 有数据、50 题基线执行准确率 ≥75%(PoC 原型)。

### P1 MVP(W4~W9)——"问数+对比+趋势"可用

- **范围(含)**:交易/商品/用户 3 域、20~25 个 P0 指标;分析模式 M1~M4;Chat 前端(流式、图表、口径脚注、SQL 溯源);语义服务+编译器;执行网关(AST/限流/缓存/水位);trace 落库;Golden Set 扩至 100 题 + 评测 runner。
- **范围(不含)**:归因/漏斗/分群/相关性、管理台、IM、多轮下钻(仅基础指代消解)。
- **交付物**:可内测系统、评测报告、ADS 建模需求交付并落地。
- **准出(M1)**:top-100 执行准确率 ≥85%;幻觉率 ≤2%;P95 < 20s;内测用户周活跃 ≥ 3 人且 👍率 ≥ 60%。

### P2 分析引擎与体验完善(W10~W15)——成为"分析助手"

- **范围(含)**:模式 M5~M8(归因/漏斗/分群/相关性);多轮下钻与澄清体系;管理台(语义编辑/评测/审计/口径查询页);反馈闭环与错例周会机制;营销/流量/售后域接入(+10~15 指标);安全:RBAC、行级权限注入。
- **交付物**:分析能力全量上线、管理台、错例看板、试用培训材料。
- **准出(M2)**:执行准确率 ≥90%、澄清合理率 ≥85%、幻觉率 ≤1%;管理层全量试用;连续两周 👍率 ≥ 75%。

### P3 生产化与验收(W16~W19)

- **范围(含)**:安全合规清单收口(07 文档 §7)、IM 入口(企微/飞书,限 P0 查询)、压测达标、HA/备份/监控告警、运维手册与值班交接、(可选)StarRocks 升级评估结论。
- **准出(M3)**:06 文档全部门槛达标;渗透测试通过;审计演练通过;运维手册评审通过;**正式验收会**。

### P4 运营优化(W20+)

双周迭代:错例修复 → 语义扩充(每月 10~20 新题入 Golden Set)→ 特性增强(周报草稿、订阅推送、实时 GMV、明细下钻,按管理层反馈排期)。

## 7. 验收标准汇总(正式验收会)

1. 功能:8 类典型问题全部覆盖并演示通过(以 04 文档 §4 八问为演示脚本)。
2. 准确率:top-100 Golden Set 执行准确率 ≥95%、幻觉率 ≈0、澄清合理率 ≥90%(报告随验收交付)。
3. 性能:P95 端到端 <12s;5 并发压测无错误。
4. 安全:渗透测试与审计演练通过(07 §7 全勾选)。
5. 运营:培训完成、引导问法上线、错例周会机制运行 ≥4 周、试用 👍率 ≥85%。
